# Regression scripts

One row per spec file: what it's called, the exact command to run just that one, and
what it proves. See [README.md](README.md) for setup, prerequisites, and the full
teardown/`SKIP_TEARDOWN` story for the specs that have one.

Run from the `regression/` directory. All commands assume the backend + Postgres are
already running (see README.md's Prerequisites).

**`PublicApiRateLimiter` is off when the backend runs locally** - `app.public-api.rate-limit-enabled`
defaults to `false` in `application-local.yml` (it's still fully on in every deployed
environment, including prod). This is why the specs below don't need any pacing waits
between API-heavy steps; if you ever point these at a deployed backend instead, that
30-requests/60s guard is real there and back-to-back public API calls can 429.

## Whole-suite commands

```bash
npm test                 # every spec, headless
npm run test:headed      # every spec, visible browser
npm run test:ui          # Playwright's interactive UI mode
npm run report           # open the last run's HTML report
```
