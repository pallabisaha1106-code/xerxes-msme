## Maintenance

Edit data/category-products.json, then run category-review/build_catalogue.py using the bundled Python runtime. References are based on original filenames, remain stored in the catalogue and must not be regenerated when editing metadata. Run build_more.py afterwards to refresh the More tabs.

WhatsApp messages use the existing configured number and canonical domain. Public product URLs identify the final category page and anchor. They can be verified locally now; new public anchors become available only after an explicitly approved future publication.

Shared navigation, CSS, scripts, security settings and unrelated pages are untouched. New category styles apply only to replacement/new pages.
